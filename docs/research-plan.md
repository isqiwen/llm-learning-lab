# 研究计划：从复现到问题驱动

## 目标与边界

长期主方向为 **LLM Systems + Reasoning/Coding Agents**。第一轮不追求从头训练前沿规模模型，也不要求把所有 Agent 框架、并行策略或新论文都实现一遍。研究成果可以是正向、负向或边界结论；新颖性需要相关工作审查，不能因为自己第一次实现就称为原创。

## 三条贯穿主线

**模型线**：理解目标函数与架构 → 独立实现 → 控制训练变量 → 可靠评估。对应 M1–M5。

**系统线**：正确性 reference → 内存/FLOPs 模型 → profiling → 单一优化 → 复测。对应 M4/M6，共享代码与测量。

**研究方法线**：读论文时列假设与反例 → 做低成本 pilot → 记录失败 → 复现主张 → 提出最小新假设。W09 起就练习，不等到 W47 才开始。

## 研究推进门槛

| 步骤 | 必须交付 | 继续条件 |
|---|---|---|
| R0 问题筛选 | 3–5 篇相关工作矩阵、任务定义、资源评估 | 有可验证指标、合法数据与可负担范围 |
| R1 基线复现 | 固定版本、运行命令、原始测量、差异分析 | 基线可信，或复现失败原因已厘清 |
| R2 Pilot | 一个主改动与少量控制实验 | 结果值得继续或明确需要改题 |
| R3 确认性实验 | 冻结协议、预算、held-out 与消融 | 无已知污染/测量错误 |
| R4 报告 | 方法、全部结果、误差、成本、局限 | 结论与证据一致 |
| R5 决策 | continue / pivot / stop 与原因 | 下一轮问题明确，而非无限调参 |

这些步骤不是必须连续获得正结果。基线无效时先修基线；达到预算上限先暂停；出现评估泄漏则隔离污染结果并重新设计。

## 选题筛选规则

每个候选题回答：已有工作做到了什么？最小差异在哪里？什么结果会否定假设？最便宜的验证方式是什么？真实瓶颈是不是自己假设的瓶颈？需要多少独立任务/seed？如果完全没有提升，仍能学到什么？

优先选择有公开实现/明确评估、一天内能做 correctness/pilot、单卡或小 API 预算可探索的问题。论文原实验过大时缩小问题并标注，不把缩规模结果称为完整复制。只选择一个主课题，其余留 Backlog。

## 建议候选，尚未确认新颖性

### A. 固定预算下，profiling 反馈是否改善代码优化 Agent？

这是主方向候选，不是已经成立的研究结论。

任务选择一类小型 C++/GPU kernel 或算子，不同时覆盖所有语言/硬件。先建立独立正确性检查与固定 benchmark。比较：single-shot；同预算独立采样；compile/test 反馈；compile/test/profile 反馈。保持模型版本、任务集、执行时间与 token/费用预算一致或明确采用的成本口径。

主指标可定义为：隐藏正确性通过的任务中速度收益，同时单独报告整体正确率与总预算。不能只筛选成功优化的任务再报告漂亮平均加速。消融 profile 信息、反馈粒度或候选选择规则；用不参与开发的 shape/任务检查泛化。

### B. 动态推理预算能否在相同总费用下降低失败？

比较固定采样数和按不确定性/失败信号分配预算；先确定信号是否真的预测难度。成功率、费用分布与 p95 latency 一起报告。oracle 预算分配只能作为上界，不能当可部署方案。

### C. 特定 workload 的推理优化边界

研究长度/shape 分桶、缓存或小 kernel 优化中的一个因素；固定输入分布并检查 OOD 长度。优化先测瓶颈，再做改动。单一 workload 的工程优化不自动等于一般性新算法，但仍可形成可靠系统报告。

## 第一轮产物

#21 完成一项最小主张复现和至少两个有意义的消融；#36 在此基础上提交一页 proposal、实验记录、独立评价与技术报告。W52 是 review checkpoint；未完成时缩范围或延长，不要求在六周内保证出现研究突破。

推荐报告结构：Abstract、Problem、Related Work、Hypothesis、Method、Experimental Setup、Results、Ablations、Failure Cases、Cost、Limitations、Reproduction。把主张分为“测量事实”“基于证据的解释”“尚未验证的猜测”。

## 学习者与助手的分工

学习者负责关键推导/实现、亲自运行或审查实验、解释结果与确认验收；助手可以维护规划、整理公开资源、提出反例、审查代码、搭建非考核基础设施和查错。不能把助手写完代码等同学习者掌握，也不能自动将未实验的任务关成 Done。
