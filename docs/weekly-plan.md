## 防止计划失真

每周先写本周唯一核心产物，再排资源。一个任务跨两周仍保留原 Issue，不复制成多个“进度”；晚期大任务在临近执行时再拆分。看板中的 Epic 不与子任务一起计入完成率或工时。

每四周检查：真正新增的能力、可复现实验数量、阻塞原因、预计/实际时间和下一阶段范围。若只有笔记没有实验，减少阅读；若只跑脚本无法解释，暂停扩展并补推导。

本表不是启动任何自动任务、GPU 训练或付费 API 的授权。所有实际学习成果仍需本人完成与验收。
